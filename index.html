% Built-in practice data: classify iris flowers
[x, t] = iris_dataset;          % x = inputs, t = correct answers
net = patternnet(10);           % 1 hidden layer, 10 neurons
net = train(net, x, t);         % TRAINING
y = net(x);                     % OUTPUT (predictions)

Day 2 — Your cat classifier (images)

1 hTheory for images
  • Do the free Deep Learning Onramp.
  • Watch: Convolutional Neural Networks explained and MATLAB transfer learning.
  • Idea: with only 100 pictures, don't train from scratch. Start from ResNet-18 (already learned to see) and retrain it for cats. This is called transfer learning.
1 hOrganize your data (this is how you "give input") 
pets/
  cat/      (all cat pictures)
  notcat/   (everything else)

The folder name becomes the label automatically.

3 hLoad, train, test 
% 1. LOAD data (browse to your pets folder)
imds = imageDatastore("pets", IncludeSubfolders=true, LabelSource="foldernames");
[trainSet, valSet] = splitEachLabel(imds, 0.8, "randomized");

% 2. RESIZE to what ResNet-18 expects
trainAug = augmentedImageDatastore([224 224], trainSet, ColorPreprocessing="gray2rgb");
valAug   = augmentedImageDatastore([224 224], valSet,   ColorPreprocessing="gray2rgb");

% 3. BUILD network (2 outputs: cat / notcat)  -- needs R2024a or newer
classNames = categories(imds.Labels);
net = imagePretrainedNetwork("resnet18", NumClasses=numel(classNames));

% 4. TRAIN
opts = trainingOptions("adam", InitialLearnRate=1e-4, MaxEpochs=6, ...
    MiniBatchSize=16, ValidationData=valAug, Plots="training-progress");
net = trainnet(trainAug, net, "crossentropy", opts);

% 5. TEST on a brand-new picture
img = imread("mystery.jpg");
img = imresize(img, [224 224]);
scores = predict(net, single(img));
label  = scores2label(scores, classNames)

If a line errors, copy the error message into Claude and I'll help fix it. Older MATLAB versions use a slightly different setup (trainNetwork); the Deep Learning Onramp shows that style.

🧭 Big picture first (read this before the steps)

A neural network is a program that learns from examples instead of rules. You don't tell it "cats have pointy ears". You show it 100 cat pictures marked "cat" and 100 other pictures marked "not cat". It guesses, checks, corrects itself, and repeats thousands of times until it gets good. Then you show it a new picture and it answers.

The whole project is 4 things: 1) get pictures + labels → 2) load them into MATLAB → 3) train → 4) test on new pictures. Every step below is just one of these.

📥 Step A · How to find the data you want on the internet

Whatever you want the model to recognise (cats, cars, leaves, handwriting...), the process is the same: find pictures of it, sorted by label.

1. Search dataset websites (best way)

  • Kaggle Datasets: huge library, search any topic. Free account needed.
  • Google Dataset Search: like Google, but only for datasets.
  • Hugging Face Datasets: filter by "Image Classification".
  • Roboflow Universe: many small, topic-specific image datasets.
  • Papers With Code Datasets and Open Images: large research datasets.

Search tip: type your topic + image classification dataset into Google or Kaggle, e.g. "plant leaf disease image classification dataset".

2. Collect your own

  • Take photos with your phone. Your own photos are great for testing.
  • Save images from web searches by hand, or with a "download all images" browser extension. Many web images are copyrighted, so use them only for personal learning, not to publish or sell.

3. Check a dataset before downloading

  • Labels: are images sorted into folders by class, or is there a CSV file of labels?
  • Size: ~100 to 300 images per class is enough to start with transfer learning.
  • License: read the licence note (many are free for learning).
  • Variety: different angles, backgrounds and lighting.

4. Get it into the format MATLAB likes

Unzip the download and arrange it as one folder per class (pets/cat, pets/notcat...), then upload it as in Step 1. If the dataset has a CSV of labels instead, you can attach labels yourself:

imds = imageDatastore("images");              % all pictures, no labels yet
T = readtable("labels.csv");                  % columns like: filename,label
% Check the order of the files matches T before doing this:
imds.Labels = categorical(T.label);

Then continue from Step 2. The code doesn't change, whatever your topic is.

💡 In simple words: Think of it like teaching a little kid with flashcards. You need lots of pictures, and each one needs the right name on it. A dataset is just a big box of already-labelled flashcards that someone else made for you.
🎥 Watch: 🔎 search: download a Kaggle dataset · 🔎 search: Kaggle for beginners

Step 0 · Know the MATLAB screen

  • Command Window: type one line, press Enter, it runs immediately. Good for testing.
  • Editor: Home → New Script. Write many lines here, then click Run (green triangle). Save as cat_classifier.m.
  • Current Folder panel (left): shows the files MATLAB can see. Your data must be inside this folder.
  • Workspace panel (right): shows your variables.
  • % starts a comment (ignored by MATLAB). A ; at the end of a line hides its output.
💡 In simple words: MATLAB is like a workshop. The Command Window is where you shout one instruction at a time. The Editor is where you write a whole recipe (a script) and then press Run so MATLAB does every line in order.

Step 1 · Put your data where MATLAB can find it

  1. On your computer, make a folder called pets. Inside it, two folders: cat and notcat.
  2. Put ~100 cat photos in cat and ~100 other photos in notcat (.jpg or .png).
  3. MATLAB Online: in the Current Folder panel, click Upload (or drag the whole pets folder in). Desktop MATLAB: put pets inside the folder MATLAB shows as current.
  4. Check it worked by typing in the Command Window:
ls pets            % should show: cat  notcat
ls pets/cat        % should list your cat pictures

If it says "not found", MATLAB is looking in a different folder. Type pwd to see where you are.

💡 In simple words: MATLAB can only see files inside its Current Folder, like a person who can only see things in the room they're standing in. Folder names are how you tell it the answer: pictures in the folder called cat are cats.
🎥 Watch: ▶ MATLAB Onramp (free course, covers folders and files) · 🔎 search: upload files to MATLAB Online

Step 2 · Load the data into MATLAB

imds = imageDatastore("pets", IncludeSubfolders=true, LabelSource="foldernames");
  • imds is just a name you choose. It becomes a "list of all your images" (a datastore); the images aren't all loaded into memory at once.
  • "pets" = the folder to read.
  • IncludeSubfolders=true = also look inside cat and notcat.
  • LabelSource="foldernames" = the folder name is the correct answer (label) for each picture.

Check it:

countEachLabel(imds)      % table: how many cat vs notcat
img = readimage(imds, 1); % read the first picture
imshow(img)               % look at it
imds.Labels(1)            % its label

This is how you give the input. The pictures are the input, and the folder names are the answers it learns from.

💡 In simple words: imageDatastore makes a list (like a playlist) of all your picture files and remembers each one's label from its folder name. It doesn't open every picture yet, so your computer doesn't get overloaded.
🎥 Watch: 📄 MathWorks guide: Create and Explore Datastore for Image Classification · 🔎 search: imageDatastore

Step 3 · Split into training and validation

[trainSet, valSet] = splitEachLabel(imds, 0.8, "randomized");

80% of pictures go to trainSet (the model studies these). 20% go to valSet (a pop quiz with pictures it never studied). This tells you whether it really learned or just memorized.

💡 In simple words: Like studying for an exam: you learn from your textbook (training set) but get tested with new questions (validation set). If you were tested on the exact same questions, you could just memorize the answers and fool yourself.
🎥 Watch: 🔎 search: train / validation / test split · 🔎 search: overfitting

Step 4 · Resize the pictures

trainAug = augmentedImageDatastore([224 224], trainSet, ColorPreprocessing="gray2rgb");
valAug   = augmentedImageDatastore([224 224], valSet,   ColorPreprocessing="gray2rgb");

ResNet-18 only accepts 224×224 colour images. This line resizes every picture automatically, and gray2rgb converts any black-and-white photo to colour so nothing crashes.

💡 In simple words: The network is built like a picture frame that only fits 224×224 pictures. Your photos come in all sizes, so this step squishes or stretches each one to fit the frame.
🎥 Watch: ▶ MathWorks: Deep Learning for Engineers (covers preparing data) · 🔎 search: augmentedImageDatastore

Step 5 · Create the network

classNames = categories(imds.Labels);   % {"cat"; "notcat"}
net = imagePretrainedNetwork("resnet18", NumClasses=numel(classNames));

This downloads ResNet-18 (a network already trained on 1 million pictures) and replaces its last layer with a layer that has 2 outputs: cat and notcat. This is the output layer you asked about. Its size = number of classes.

💡 In simple words: Imagine hiring someone who already knows how to see (edges, shapes, fur, eyes) from looking at a million photos. You only teach them the last bit: your 2 categories. That's transfer learning, and it's why 100 photos are enough.
🎥 Watch: ▶ MathWorks: Transfer Learning in 10 Lines of Code (4:41) · 📄 MathWorks: What is transfer learning?

Step 6 · Training settings, then train

opts = trainingOptions("adam", ...
    InitialLearnRate=1e-4, ...   % how big each learning step is
    MaxEpochs=6, ...             % how many times it sees all pictures
    MiniBatchSize=16, ...        % pictures processed at a time
    ValidationData=valAug, ...
    Plots="training-progress");

net = trainnet(trainAug, net, "crossentropy", opts);

A window opens showing a live graph. Accuracy should go up and loss should go down. The ... just continues a line onto the next one. Training can take a few minutes.

💡 In simple words: Training = the network guesses, checks the right answer, and adjusts itself a tiny bit, over and over. Epoch = one full pass through all your pictures. Learning rate = how big each adjustment is. Batch size = how many pictures it looks at before adjusting.
🎥 Watch: ▶ 3Blue1Brown: Gradient descent, how networks learn · ▶ MathWorks: Deep Learning for Engineers (training a network) · 🔎 search: epochs, batch size, learning rate

Step 7 · Test on a new picture (get the output)

Browse for a picture with a file-chooser window:

[file, folder] = uigetfile({"*.jpg;*.png"}, "Pick a picture");
img = imread(fullfile(folder, file));
imgSmall = imresize(img, [224 224]);
scores = predict(net, dlarray(single(imgSmall), "SSC"));
label = scores2label(scores, classNames);

imshow(img)
title("I think this is: " + string(label))

On MATLAB Online, if the chooser doesn't open, upload the picture and use img = imread("mystery.jpg"); instead. Never use a photo from your training folder, since that's cheating. Use a fresh one.

💡 In simple words: This is the exam day. You pick a brand-new picture, the network gives a score for each category, and scores2label picks the category with the highest score. That's the output.
🎥 Watch: ▶ MathWorks: Transfer Learning in 10 Lines of Code (shows testing a picture) · ▶ Deep Learning Onramp (free, hands-on)

Step 8 · Save your trained model

save("catModel.mat", "net", "classNames");   % save
load("catModel.mat");                         % load it later, no retraining
💡 In simple words: Training takes time, so you save the brain to a file (catModel.mat) and load it later instead of training again, like saving a game.

Common errors and fixes

  • "Unrecognized function imagePretrainedNetwork": your MATLAB is older than R2024a, so tell me your version and I'll rewrite it.
  • "Unable to find or open pets": wrong folder. Use pwd and ls.
  • ResNet-18 not found: install the "Deep Learning Toolbox Model for ResNet-18 Network" add-on.
  • Low accuracy: add more varied pictures, and make sure notcat has lots of different things.
